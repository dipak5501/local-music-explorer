# Local Music Explorer

Discover and explore local music venues, concerts, and events in your area.

## Trend

Music streaming and live events have seen a surge in interest, with people increasingly seeking out local experiences over global ones.

## Users

music lovers,local event organizers,venue managers

## Setup

```bash
npm install
npm test
npm run build
npm start   # http://127.0.0.1:8787/
```

## Stop

Ctrl+C
